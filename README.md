# LiveStream

A dark, creator-first video platform starter. It includes long-form videos, Shorts, a creator upload interface, live-stream discovery, and a demo live chat.

## Run locally

```cmd
npm install
npm start
```

Open `http://localhost:3000` in your browser.

## Before production

- Connect user authentication and a database.
- Connect Cloudinary, Supabase Storage, or Amazon S3 for real video uploads.
- Connect LiveKit or Agora for real live video and live chat.
